# Credits and third-party assets

## Demo evidence photograph

`public/demo/meter-reading.jpg` — *Aclara I-210+ single phase smart electricity meter* by
[277volts](https://commons.wikimedia.org/wiki/User:277volts), via Wikimedia Commons.
Licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The file is
unmodified apart from being scaled to 1280 px wide.

This photograph exists so judges can exercise the evidence-verification flow without taking a
photo of their own meter. It is a real photograph, and the vision model reads the register
(74,590 kWh) from it.

`public/demo/price-tag.jpg` and `public/demo/lease-envelope.jpg` are original illustrations
created for this project and are covered by the repository's MIT licence.
